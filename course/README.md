# Course: Bahasa Jepang — Bulan Pertama

Isi course dirancang untuk komunitas kecil: 5 topik, quiz, forum, glossary, H5P, badge, dan SCORM.

## Status berkas

- `soal.gift` — bank soal siap import ke Moodle (Question bank → Import → GIFT).
- `bahasa-jepang.mbz` — **sudah dibuat** dari Moodle prau (5 topik + quiz + forum + glossary).

## Cara menghasilkan .mbz

1. Buka Moodle → course **Bahasa Jepang — Bulan Pertama**.
2. Site administration → Courses → Backup → pilih course ini → selesaikan sampai selesai.
3. Unduh file `.mbz`, lalu simpan sebagai `course/bahasa-jepang.mbz`.
4. Commit ke repo supaya instalasi berikutnya langsung mengimpornya.

## Cara impor soal

Site administration → Questions → Question bank → Import → format **GIFT** → pilih `soal.gift`.
