PANDUAN IMPOR KE MOODLE
=======================

A. MATERI (Book)
1. Di kursus: Aktifkan Mode Edit > Tambahkan kegiatan atau sumber daya > Buku (Book).
2. Beri nama "Bahasa Jepang Bulan Pertama", simpan, lalu buka Buku tersebut.
3. Menu (ikon roda gigi) > Impor (Import).
4. Unggah buku-jepang-bulan1-moodle-book.zip, pilih "Satu file HTML = satu bab" jika ditanya, lalu Impor.
5. Setelah selesai, cek urutan 14 bab dan tampilan tabel.

B. SOAL (Quiz)
1. Di kursus: Bank soal > Impor.
2. Format file: Moodle XML. Unggah quiz-bahasa-jepang-bulan1.xml. Hasil: 28 soal dalam 4 kategori. Lalu impor juga quiz-tambahan-bahasa-jepang-bulan1.xml (11 soal untuk bab angka, waktu, kata kerja, kata sifat).
3. Buat Kuis baru > Edit kuis > Tambah > Dari bank soal; pilih per kategori.
4. Kunci jawaban ada di soal (tidak tampil di materi). Atur "Umpan balik" di pengaturan kuis agar siswa melihatnya setelah mengerjakan.

CATATAN
- File dibuat dan divalidasi secara struktur; belum diuji di server Moodle Anda. Coba impor di kursus uji dulu.
- Cek semua tautan di bab "Sumber Belajar" sebelum dipublikasikan.
- Audio pengucapan belum termasuk. Rekam atau tambahkan lewat aktivitas H5P / berkas audio.
